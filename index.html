Welcome to Our Bootcamp

Ready to to unlock your digital superpower? At HerCode Initiative, you will dive into magic behind web pages, games, and apps.
Discover how coding works, build your very first website from scratch, and team up with other creative girls changing the tech world!

Skills you will learn;

  • Building responsive web pages using HTML
  • Designing beautiful layouts with modern CSS
  • Creating interactive elements using JavaScript
  • Using version control basics to collaborate
  • Problem solving like a real software engineer

Requirements to join:

  • Identify as a girl
  • Be between the age of 14 to 20 years old
  • Have access to a laptop or computer with internet
  • Able to attend 5 days a week live coding sessions
  • No prior coding experience required, just curiosty!
